# M4：持久候选来源、精确核验与全栈集成

## 需求与边界

在既有聊天检索、收藏、历史和交易确认上，加入按会话持久的候选与比较。检索结果可以继续被新搜索/零结果替换，候选独立保留；刷新与重启恢复同一集合。实现基线为 M3 `1871718c8b6731e5c770ac9cd299e2c180b3e21e`，仅本地提交，不推送或部署。

候选是保存时的历史信息，不是有效报价、库存预留、支付或物流单。收藏仍是原产品级功能，收藏/工具小卡不被自动升级成可信候选来源。原 M2 的身份、公开前过滤、请求键和明确确认/批准流程保持有效。

## 实现

- `ag_ui_journal.py` 新增内容寻址的目录快照与 run 引用表。composition 从 M3 目录登记注入只读版本；首次 reserve 在同一事务绑定，旧 run 重试和重启不补写当前身份。目录快照共享存储，避免每个 run 复制整个目录。
- `candidate_workspace.py` 持久层与前端详见 [持久层](M4-候选持久层.md)、[前端](M4-持久候选前端.md)。候选上限 30，比较上限 3；按商品+SKU去重，随机候选 ID；CAS revision与成功 request_id 在同一 SQLite 事务，重放先于旧版本/来源校验。
- 保存只接受 run/product/SKU 引用，不接受客户端报价或身份。校验签名买家、会话和来源归属，再从公开 journal 提取完整卡。run 绑定与卡片身份/条款一致才保留身份；旧来源、缺失来源和无法证明的恢复卡保持未知，不能借当前目录补签。
- ProductCard 的 source_locale 现在独立于 source_language 输出。真实目录有站点、无语言时，不能因展示序列化漏站点而丢失身份；旧日志不回填。
- `CandidateWorkspaceService.verify` 只走精确 product/SKU ID 的本地目录路径，不装配模型、向量或重排客户端。先校验目录版本、active、商品、identity_hash、terms_hash、generation，再读取当前库存/目的地；返回前重查目录登记防止期间变化。
- 五个签名/owner保护入口：集合 GET/POST，候选 DELETE，比较 PUT，以及候选 verification GET。所有写入需要 request_id+expected_revision；返回结构化409，数据库故障503，不把错误冒充空集合。
- 验证返回 available/out_of_stock/unavailable/identity_mismatch/unknown_identity/terms_changed。仅 available给出当前目录卡；前端展示历史与当前差异后才进入原 OrderIntentForm。prepare再次核价格/库存和配送，用户仍须明确批准。
- 实际 App 使用独立候选 controller，保留待核对写入原键；旧响应不能回退 revision，切会话/身份/请求代次丢弃迟到回包。两标签409先刷新，再由用户决定重试；刷新失败不能使用旧版本换新键。焦点/上线恢复读取。
- `scripts/ci/mock_smoke.py` 扩展签名真实回环 HTTP 冷启动、候选/比较/冲突/重放/重启与零新增模型核验。新后端源文件和三组测试纳入 Harness impact与每次必跑安全契约。

## 验证与失败保留

完整后端2572通过（3项委托独立Locust且14项通过）、前端425通过、固定合同1319通过、最终签名回环HTTP通过。最终分层结果、指纹与明确阻塞统一见 [M4集成证据](../../../eval/verification/2026-10-16-m4-integration/README.md)。所有模型请求仅来自回环假服务；没有使用真实付费模型或真实买家数据库。

- API首轮误用了旧类名 SqlSessionStore，收集失败；改用当前 SqlFencedSessionStore。第二轮暴露 source_locale 依赖语言的真实缺口，4失败/51通过；修复后先66通过，再补跨搜索/零结果/期间目录变化/退市后69通过。原始日志见 [API证据](../../../eval/verification/2026-10-16-m4-api/)。
- 独立Locust首次直接选择 uv 包缓存中的 Python，缺httpx收集失败；随后使用离线锁定隔离环境完整14通过。未下载新依赖。
- 持久层/前端各自原始失败与修复均保留，不改写旧证据。完整回归不使用挑选少数场景代替。

## 启用、回退与已知限制

新增表在既有 journal 同库初始化，不改写旧 run、收藏、订单或确认。启动时依赖 M3可信目录登记；目录未知仍按 M3失败关闭。升级前备份 journal与交易库的一致副本。回退先停写，恢复匹配代码/目录/备份；不要删候选、请求键或目录表绕过保护，旧代码不得并行混写。

第一期每个会话集合有界；成功请求重放记录和内容寻址目录快照不自动过期，存储随操作/目录版本增长。跨库目录核验不是预留或全局事务；最终提交继续由 M2/M3原子确认保护。当前不提供从收藏/工具小卡直接加入、批量迁移旧本地比较、线上容量承诺或收益指标。

真实浏览器在既有沙箱无法启动，禁止绕过该限制；本轮以实际 App+SDK mock HTTP测试和生产构建作离线证据，不能标为真实浏览器通过。真实模型 smoke 缺评测凭据，人工类目/译文QA、上游许可及真实容器/TLS/容量门禁仍按前序记录未完成，不因M4离线通过而关闭。
