# T2 增强与翻译缓存入口

准备阶段完成显式模型调用入口与本地夹具验证，真实模型调用 0。随后完成 20 件真实小批和两次缓存复跑，实际状态见下文；正式商品目录仍待生成。入口分支 `feat/T2-enrichment-runner` 从 `33607e1` 开始，仅作本地提交。

## 变更与启用

- `scripts/esci/enrich_catalog.py` 分别提供 `--enrich` 和 `--translate`。沿用 `load_settings`、现有网关地址、模型和 `GatewayThrottle`，请求温度为 0；并发取配置与 2 的较小值。
- 商品提示词版本为 `product-enrich-v1`，只接受固定类目和材质枚举；中文提示词版本为 `translate-zh-v1`。完整响应、精确 JSON 结构和枚举在 API 边界校验，格式错误逐条记为失败并保留原始响应。
- 商品按 `(locale, asin, prompt_version)` 缓存，译文按 `(locale, query_id, prompt_version)` 缓存；输入内容指纹防止原文变化后复用旧结果。已完成缓存与格式失败均可零调用重跑。
- 超时沿用 `LLM_MAX_RETRIES` 上限和 6、18 秒退避。HTTP 服务错误、连接错误及重试耗尽会明确失败退出；每条完成结果立即写入缓存，故障后续跑只调用缺失条目。
- `finalize_catalog.py` 的 Exact 商品类目众数判定与最终抽样提为共用逻辑。翻译入口先确定最终留出 300 条，再按站点及类目抽取 200 条，与最终 `crosslingual-zh.jsonl` 对齐。
- 默认缓存位于 `data/esci/enrichment-v1.jsonl` 和 `data/esci/translate-zh-v1.jsonl`；现阶段仍受现有数据忽略规则管理。正式 T2 交付时再放行实际数据文件。应用运行时配置保持原样。

## 实际调用规模与后续命令

现有预选计划包含 15,860 件去重后的站点商品。完整填充需要 15,860 次商品增强与 200 次中文翻译，共 16,060 次基础调用，超时重试另计。本次仅执行 20 件真实小批，实际延迟与供应商用量见下文；全量耗时、全量用量与费用均未知。

在项目根目录可先取 20 件商品做小批验证，并将结果写入正式逐商品缓存。以下为命令用法示例；本次实际准备目录与验证命令见下文：

```sh
mkdir /tmp/voyacart-t2-sample-20
head -n 20 eval/verification/2026-10-14-t2-input-plan/enrichment-inputs.jsonl > /tmp/voyacart-t2-sample-20/enrichment-inputs.jsonl
.venv/bin/python -m scripts.esci.enrich_catalog --enrich --prepared /tmp/voyacart-t2-sample-20 --output eval/verification/<新的小批证据目录>
.venv/bin/python -m scripts.esci.enrich_catalog --enrich --prepared /tmp/voyacart-t2-sample-20 --output eval/verification/<新的缓存重跑证据目录>
```

完整商品增强完成且全部状态为成功后，可运行翻译与定稿：

```sh
.venv/bin/python -m scripts.esci.enrich_catalog --enrich --prepared eval/verification/2026-10-14-t2-input-plan --output eval/verification/<新的商品增强证据目录>
.venv/bin/python -m scripts.esci.enrich_catalog --translate --prepared eval/verification/2026-10-14-t2-input-plan --output eval/verification/<新的中文翻译证据目录>
.venv/bin/python -m scripts.esci.finalize_catalog --prepared eval/verification/2026-10-14-t2-input-plan --enrichment data/esci/enrichment-v1.jsonl --translations data/esci/translate-zh-v1.jsonl --output eval/verification/<新的正式产物目录>
```

回退时停用上述显式入口并保留缓存和运行证据；现有目录及应用数据不会被这些命令自动替换。
