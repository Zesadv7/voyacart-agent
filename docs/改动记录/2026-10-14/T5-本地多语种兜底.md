# T5 本地多语种向量兜底

2026-10-14。用户确认优先后端与前端、数据维持试运行规模并统一交付 PR。本阶段完成运行时能力与工程验收，中文 ESCI 模型选择和效果评测继续待办。实现分支 `feat/T5-local-fallback` 基于 `7f29c08`，随后汇入 `feat/backend-frontend-runtime`。

## 实现

- 将原评测编码实现提升到 `app/infrastructure/embedding/local_multilingual.py`，旧模块保留兼容导入。继续使用 128 token 分块、加权平均和归一化；编码在工作线程中执行。
- `LOCAL_EMBEDDING_FALLBACK=0` 保持原检索行为。开启时，远端向量失败或空候选转入本地向量；本地失败保留关键词／BM25 路径。硬约束与补召回沿用既有逻辑；结果标记 `local_embedding`。
- `app/composition.py` 为本地模型创建独立 Qdrant 集合与模型身份。使用嵌入式存储时分开物理目录，服务端模式共享 Qdrant 服务并分开集合。集合名配置冲突时尽早报错。
- 运行时只加载预先准备的缓存。模型及编码内容变化触发既有增量索引流程；关闭时释放本地索引。
- Docker 安装已有 retrieval 依赖组，Compose 传递两个默认关闭的配置项。镜像依赖体积增加，模型权重仍由准备命令写入数据卷。

## 启用与回滚

见 [README](../../../README.md#本地多语种向量兜底)。先安装 retrieval 依赖、准备模型，再设置 `LOCAL_EMBEDDING_FALLBACK=1`。默认集合 `voyacart_products_local`，独立于远端商品与知识库。关闭开关并重启即可回到原检索链路，缓存与已有集合保留。
