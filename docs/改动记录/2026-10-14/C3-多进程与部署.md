# C3 多进程与部署

## 需求与实现

会话库增加 session_tool_history(session_id, tool_name)，按唯一键记录工具调用。SEQUENCING_PERSISTENCE_ENABLED 默认 0，开启后 Harness 读取持久历史；SQL 和 JSON 文件模式的会话库都支持。断言语义保持现状：有历史且缺检索时拒绝下单，无历史时保留警告。

两个独立进程同时请求整理上下文，现有 create_context_operation 事务与版本检查已保证只启动一次，整理逻辑保持现状。

docker/docker-compose.scale.yaml 使用 Nginx、可扩展 API/worker、单个自动化 worker、Redis、Qdrant 与共享数据卷。部署显式启用共享熔断、持久顺序记录与队列，API 使用 external 自动化模式。Nginx 等待 API 健康，通过 Docker DNS 解析副本。

可选 mock profile 使用 scripts/loadtest/mock_llm.py，提供流式工具参数、固定检索轨迹和确定性嵌入。当前用于链路验收，完整 L1 的 300 token 与 10% 下单轨迹仍待补齐。

前端锁文件的 304 个内网下载地址替换为 npm 官方地址，版本与完整性值保持原样。部署配置与假模型源文件打入镜像，适配本机 Colima 对临时目录的挂载限制。商品展示 DTO 补传 external_product_id。
